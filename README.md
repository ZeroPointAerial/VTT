# VTT

Foundry VTT content by Zero Point Aerial.

## Modules

### The Drowned Bell of Saltmere
A D&D 5e (2014) one-shot for four to five level 5 characters. Requires Foundry v13+ and dnd5e 5.0+.

Install from Foundry's Setup screen: **Add-on Modules → Install Module**, paste this manifest URL:

```
https://raw.githubusercontent.com/ZeroPointAerial/VTT/main/drowned-bell-saltmere/module.json
```

See [`drowned-bell-saltmere/README.md`](drowned-bell-saltmere/README.md) for contents.
